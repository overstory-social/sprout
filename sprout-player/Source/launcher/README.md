The launcher's card (350×155), icon (32×32) and launch image (400×240), one bit a pixel.

The picture is the rat goblin from Dante Gabriel Rossetti's frontispiece to Christina Rossetti's
_Goblin Market and Other Poems_ (1862), which is in the public domain
(https://commons.wikimedia.org/wiki/File:Goblin_Market_and_Other_Poems_-_Rossetti_(1862)_-_frontispiece.png).

The lettering is set in Bitmore Medieval Bold and Cuberick Bold, Panic's Playdate fonts from the SDK's
`Resources/Fonts`, under the Creative Commons Attribution 4.0 International licence
(https://creativecommons.org/licenses/by/4.0/).
