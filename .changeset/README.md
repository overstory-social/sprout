# Changesets

`npx changeset` to add one with a change; `npm run version` folds them into the
manifests and CHANGELOG.md; `npm run release` builds and publishes. The two
packages are a `fixed` group: they always carry the same version.

0.1.0 was published by hand from a clone (the manifests and CHANGELOG.md
already carried it); every release after it goes through a changeset here.
