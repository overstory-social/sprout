# Reviews of the Sprout design spec (2026-09-20)

Five independent critiques of `../sprout-design-spec.md` as it stood on
2026-09-20, one perspective each, produced by Opus-class reviewers
following the briefs in `../sprout-review-prompts.md`. Each reviewer saw
the shared preamble and its own brief only — not the other briefs, not
the other reports, and not the conversation that produced the spec. They
were told that only the spec, the working notes and the build backlog
are canonical, and that everything else in the repository describes a
previous version of the language.

Line numbers in the reports are `cat -n` positions in the spec on that
date; they will drift as the spec is edited.

- `review-1-consistency.md` — internal consistency, over all three canonical docs
- `review-2-implementability.md` — decidability, phase ordering, cost, atomicity
- `review-3-writer-ergonomics.md` — a cold reader writes a world from the spec alone
- `review-4-player-ergonomics.md` — the worked example played as a real person would
- `review-5-engineer-ergonomics.md` — the implementation shape and where the spec fights it
- `synthesis.md` — where the five converge, where they conflict, and a suggested order of repair
